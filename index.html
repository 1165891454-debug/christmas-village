需要先配置 Firebase ☁️

本页需要连接云端才能在两部手机间同步。

  1. 打开 firebase-config.js，按文件内注释填入你的 Firebase 配置
  2. 在 Firebase 控制台开通 Realtime Database（建议新加坡区域）
  3. 把 README 中的安全规则粘贴到数据库「规则」页并发布
  4. 刷新本页
